我做了一个lean证明的塌缩实验
	
这是一个带mathlib,并成功绕过内核审查的定义塌缩实例，为你们展示塌缩机制在逻辑上可能发生，谁写的1700万行代码，就得全部审完，别拿个机器验证，程序验证就当真理了，没审完就是验证不足的宣称
	
lean，Con-Leche 能够兜底形式逻辑的一致性，不能自动兜底数学定义的忠实性；
